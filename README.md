# nano-forecaster

Projet de recherche appliquée sur la prévision multi-horizon de la cible `OT`
du jeu ETTh1. Le protocole, les résultats mesurés et les limites seront consignés
ici par le pipeline reproductible. Aucun résultat n'est renseigné avant un run.

## État du banc d'essai

Implémentation en cours. Voir `configs/default.yaml` pour l'expérience principale
et `configs/small.yaml` pour la validation rapide.
